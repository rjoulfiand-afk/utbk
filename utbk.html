Keamanan, Pemeriksa Integritas & Backup Data

Kelola cadangan belajar `.json`, enkripsi catatan AES-GCM-256, dan periksa status integritas data lokal secara transparan.

1. Cadangkan & Pulihkan Data (.json)

Unduh seluruh progres modul, arsip siklus harian, dan catatan ke file .json. Saat pemulihan, sistem memvalidasi ukuran file (maks 2 MB), struktur skema, tipe data, dan menampilkan pratinjau sebelum menimpa data.

3. Enkripsi Catatan Pribadi (WebCrypto AES-GCM-256)

Lindungi isi tab Catatan dengan kunci kriptografi yang diturunkan dari PIN/frasa sandi melalui PBKDF2-SHA256 (600.000 iterasi, salt acak 16 byte) dan dienkripsi menggunakan AES-GCM-256 (IV acak 12 byte baru setiap penyimpanan). Aplikasi tidak menyimpan hash PIN.

4. Mode Sumber Materi & Panduan AI Aman

Secara default, aplikasi berjalan 100% Offline menggunakan Bank Kurikulum Internal tanpa mengirim data ke mana pun. Kunci API tidak pernah ditanam di kode sumber.

  • Penyimpanan Sesi Saja: Bila memakai kunci API sendiri pada pengembangan lokal, simpan hanya di sessionStorage (otomatis terhapus saat tab ditutup) atau gunakan Cloudflare Worker dengan validasi header Origin dan rate limit.
  • Aturan Ollama Lokal: Jangan pernah mengatur OLLAMA_ORIGINS="*" karena situs berbahaya mana pun yang terbuka di browser dapat mengakses LLM lokalmu. Batasi secara spesifik hanya ke origin situsmu.
